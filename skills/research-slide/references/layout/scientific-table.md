# Scientific tables: retain an independent evidence object

A scientific table can supply the explanation through grouped headers, condition stubs, units and values. Select the page family from its role: dense comparison02, setup/results03, diagnostic06, bounded ablation07/10/12, brief report plus independent paper evidence15, pure scientific readout19, or compact scientific status/caption23. A table's presence does not choose among them.

[Example19](../author-examples/example-19-scientific-table-readout.png), `scientific-table-readout`, is a native scientific table with a small context line above it. It uses35pt purple Frank Ruhl Libre Bold topic,10pt gray Montserrat context, and8pt black Arial table. The context is a scientific caption, not a10pt deck-bullet default. The table occupies x66.09–646.37,y134.53–331.28pt:80.6% width and39.2% area. Related metric families have bold grouped gray headers, ordinary subheaders, and gray shared-condition stubs; white data cells use .75pt dark-gray rules. Observed header heights30/46.75pt and30pt data rows are local measurements, not a required schema. The source has no focus or winner marks. A table-led page may end at the table without adding an explanatory sidebar.

Select three independent controls from the current comparison:

- **Structure:** group related metrics, retain shared condition/format stubs where they reveal controlled scope, and keep full meaningful method tokens. Context, units, format semantics and denominator scope may live in table headers or the figure itself. Use a caption only for interpretation that is not already recoverable there.
- **Focus:** mark a configuration or row that the current report discusses when that focus is meaningful. One restrained row fill or outline can serve this role. Its cells may lose some metrics. A source's green operating row is one local variant, not the author's universal table composition.
- **Winning/comparison emphasis:** mark cells only under the declared comparison direction and scope. Keep ties, exceptions, exclusions and ranking status accurate. Winner emphasis and selection fill may coexist, but neither implies the other. Neutral grouped headers remain neutral when no emphasis is justified.

Preserve the scientific object's visual identity separately from deck prose. A paper-table image may have serif headers, internal caption, ranking colors and its own rules; retain them intact when using the supplied asset. A native table may use the black/sans and gray hierarchy documented here. Reconstructing a supplied scientific table as a generic navy results card changes its identity. Shared slide branding does not license replacing scientific typography or metric grouping.

Adapt table footprint and the surrounding body scale together. Dense8–10pt table labels coexist with14pt notes in several report families; other table-led pages have only a small context caption. More available width does not justify enlarging every cell and adding prose around it. If current facts exceed the selected family, change the composition for that reason and preserve all required columns, conditions and numeric truth. Repair clipping, token loss and source scientific errors narrowly.

Compare [runtime focus](runtime-focus-table.md) for its distinct blue/gray focus variant and [evidence-led readout](evidence-led-readout.md) for an independent paper figure beneath ordinary14pt deck notes. Science-free records are in [focused starters](../author-examples/focused-layout-starters.json); native source19 provenance is in [broad measurements](../author-examples/measurements-broad.json#page1Based=347).


## Black/sans primary scientific caption with status: example23

[Example23](../author-examples/example-23-scientific-status-caption.png), `scientific-status-caption`, has a14pt black Arial Bold primary scientific method/model/conditions heading at x78.35,y45.63–59.63. It has **no separate purple topic title**. Ordinary10pt gray Montserrat notes at12pt baseline pitch describe the implementation, implemented changes and explicitly pending work; Arial10pt filled/hollow markers sit at90.31/126.31 with text114.35/150.35. The narrative glyph envelope is x90.31–569.29,y74.49–170.68. These compact notes are not the14pt report hierarchy of the purple-topic table families.

The neutral native table sits at x98.01–654.40,y182.35–378.15:77.3% width and37.4% area. It uses8pt black Arial, bold white grouped headers, ordinary white data cells, left aligned labels/values and .75pt black rules. Method/configuration stubs and merged repeated labels carry comparison structure. There is no source selection fill or winner emphasis. Current meaningful focus/winning controls remain independent; retain neutrality when neither is needed. Repair any actual table/footer collision or broken scientific token locally.

Use this family when a compact scientific heading jointly carries method and conditions while internal status notes and the table complete the report. Preserve implemented versus pending status; only current supplied plans authorize pending slots. Source method/model names, values, implementation counts and row/column counts are not defaults. This is one supported author variant, not permission to remove a justified purple topic title from every page or shrink all status reports. Coupled heading/body/table scales and object roles distinguish it from readout19 and evidence-led15.
