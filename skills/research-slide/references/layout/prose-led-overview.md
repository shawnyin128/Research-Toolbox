# Layout — prose-led overview with supporting inset

Use when the main task is an intended objective and its motivation, illustrated by one compact schematic example. In the [selector](family-selector.md), distinguish this supporting-example role from a mechanism the audience must trace and from an implementation progress report. Tokens or two compared states do not by themselves establish mechanism-teaching intent.

Inspect example16 and `prose-led-overview-inset` in [focused starters](../author-examples/focused-layout-starters.json). Keep that narrative hierarchy rather than recasting it as a smaller left column with a comparison panel.

Scientific cells are square-corner23.43×25.84pt rectangles with.75pt dark-gray rules and local #EA9999/#A4C2F4 state fills. Preserve this compact shape grammar and independent local scale when adapting to current facts. It is a supporting schematic, not a set of generic cards. Current scientific data determine positions, states and row counts.

Retain the whole argument and every required relation. A short local state key can repair an ambiguous mapping without expanding the inset. Use the nested prose witness, visible state runs and minimum local labels together; do not automatically restate the same comparison in row subtitles, a full legend and a takeaway caption. Stage1 records roles and geometry only. Copy supplies concise wording and necessary scopes after selection. A stated research goal remains an intended goal, never an achieved performance result.

For a mechanism requiring transitions, choose the suitable compact/native-object family; for completed/pending stages choose workflow11. These legitimate siblings need different body/object ratios.
