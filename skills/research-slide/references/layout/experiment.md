# Layout — experimental evidence

Select the local experimental family. Preserve both a table and operation sequence when they answer different required tasks. Retain grouped metric headers, controlled-condition stubs, readable method labels and selective comparison emphasis. Use the reference's prose/table relationship and type levels. Dense evidence may lead the page; a title/repeated setup is not mandatory without a scientific purpose. Preserve every numeral. Choose focus cells/rows from the comparison and local example, not a whole-column color scheme or automatic all-maxima rule. Author density is valid when evidence remains intact.


Distinguish a brief readout from a dense table page or an explanatory report before reserving prose. When context and one scoped observation suffice above a complete scientific object, inspect [evidence-led short readout](evidence-led-readout.md). Keep surrounding body scale and figure footprint coupled; embedded table typography never supplies the default body font. Retain all current caption, ranking/exclusion, panel and row evidence. A separately drawn non-obscuring focus mark may identify the discussed row without changing rank semantics.

For tables that supply their own scientific account through headers, conditions and a small caption, read [scientific-table identity and emphasis](scientific-table.md). A table readout is distinct from an explanatory report. Preserve grouped headers, full scientific tokens, current focus and winner semantics independently; neither a green operating row nor enlarged surrounding notes is universal.
