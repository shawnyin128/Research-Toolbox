# Layout — evidence-led short readout

Use when the audience needs a brief experimental readout: a small context/condition note and one scoped observation, while one complete independently styled scientific figure carries the evidence. Compare this role with a dense native-table page and a fuller explanatory report using the [selector](family-selector.md). A table alone cannot choose the family.

Inspect example15 and `evidence-led-short-readout` in [focused starters](../author-examples/focused-layout-starters.json). The measured source has a24pt purple Frank Ruhl Libre Bold evaluation title, then14pt black Arial ordinary bullets in a shallow full-width band. Marker/text x43.83/70.29pt, baseline pitch16.8pt. The complete raster scientific figure lies x108.49–568.61,y113.89–405pt:63.9% of page width and45.9% of page area. Its991×627 aspect ratio is landscape. Its caption, key, exclusions, panels and every row remain intact. The figure's nominal serif font sizes are unrecovered raster typography, not native10pt measurements.

These body/evidence scales belong together. Two note slots do not permit a long sidebar essay, and internal table glyph scale does not justify reducing deck notes to10pt. Budget only necessary context, scoped result and reported explanation. Current scientific qualifications stay visible; concise prose and shared evidence witnesses can carry them without a second account of the experiment. Copy resolves wording after this stage. If genuinely necessary content exceeds the band, return the conflict upstream before changing the composition.

The observed native red1.5pt outline at x130.47–552.60,y195.05–209.95pt is a separate local focus layer over an unchanged figure. Permit such an annotation when current facts identify a focus and it obscures no evidence. Embedded rank colors, selection focus and winners remain separate semantics. Do not force a red rectangle onto unrelated evidence.
