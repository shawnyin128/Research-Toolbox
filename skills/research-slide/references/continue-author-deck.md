# Continue the author's existing research deck

Use the author profile only when the current references agree with it. Inspect two complete pages with similar reading tasks. In an existing Google deck, also inspect the native objects, text runs, table structure, transforms and current revision. In an existing PPTX, inspect imported objects and the actual render. A PDF supplies visual geometry and content but no editable slide master; recreate required objects honestly.

Choose a main reference by experimental function and period, not just the label “table” or “method.” Record where the reader starts, where the evidence sits, precise emphasis, and what is deliberately absent. The archive contains both table-first and discussion-first pages, different footer logos and untitled mechanisms. Do not normalize them all into one template.

In a working copy, map each original object to the new input. Preserve native objects where they fit; change dimensions only when the new evidence needs it. For each source paragraph, distinguish unchanged relevant content, changed scientific variables and irrelevant content. Retain the first, minimally update the second and remove the third. Preserve experiment uncertainty and short working labels. Never carry old values, run identifiers, notes, citations or illustrative figures into a different experiment.

For native Google text edits, the optional `inspect_slots.py` and `patch_slots.py` use fresh native page JSON. Edits identify objectId, exact before/after and optional cellLocation. Mixed formatting must remain intact; the patcher rejects multi-style spans and newlines. Apply only through the supported connector, with revision control and readback. A mismatch or concurrent change requires a new read, not a blind retry. See [Google route](google-slides.md).

A mechanism should encode the operation: shared scales line up with their groups; indexed objects retain identity; capacity changes use the same scale and fixed boundary. If data do not supply a measured magnitude, use symbolic/structural encoding. Do not replace a positional mechanism with a list of abstract method names.

For a result table retain conditions, row order, metric definitions, precision and missing-value notation. Preserve local formatting when it still carries the same meaning; remove inherited emphasis that would become misleading. Do not turn every improvement into a whole-row winner or invent a final recommendation.

Before handoff inspect the persisted target render beside the chosen non-target example, at the same size. Verify evidence footprint, title/body proportions, bullet/row geometry, exact emphasis and the last row/column/footer. Use the current user's requested scope: a one-page edit does not authorize redesigning the rest. For blind author-style acceptance follow [blind evaluation](blind-evaluation.md); the editor must not see the withheld target original before locking the generation.
