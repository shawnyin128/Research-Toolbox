# Stage 1 — composition before sentences

Input: frozen facts, the recorded family-selection decision when using isolated packets, and authorized training/style examples. Output: `layout.json`. Do not read copy guides or draft polished body paragraphs here.

1. Run the [purpose-first family selector](../layout/family-selector.md). Record report intent, each scientific object's role in the argument, current series/identity evidence and uncertainty, required scientific objects, then evidence form. In isolated runs, compare the two candidate silhouettes in the fresh selection stage before the final single-family packet; reject both if neither fits. Carry `selection.json` forward and return an incompatible selection upstream. Current identity comes from current user/deck context; the selected reference's footer cannot override it. Read canvas/type tokens in [profile](../author-profile.md).
2. Select the compatible concrete [family](../author-style-execution.md). Load only its record from [layout records](../author-examples/author-family-layouts.json) or [focused starters](../author-examples/focused-layout-starters.json), and inspect its actual image. The focused starter file indexes five promoted training images and provenance, including [short readout](../layout/evidence-led-readout.md) and [prose-led overview/inset](../layout/prose-led-overview.md). Legacy examples are in [index](../author-examples/index.md). A chart does not automatically select Goal/Experiment/Results; tokens do not automatically select a positional transformation.
3. Read one specialist: [mechanism](../layout/mechanism.md), [experiment](../layout/experiment.md), [ablation](../layout/ablation.md), or [workflow](../layout/workflow.md). Read its narrower linked module when applicable: [plot-led observation](../layout/plot-led-observation.md), [compact scientific object](../layout/compact-object.md), [runtime focus table](../layout/runtime-focus-table.md), [evidence-led short readout](../layout/evidence-led-readout.md), or [prose-led overview/inset](../layout/prose-led-overview.md).
4. Fix the silhouette before prose: title/absence and established title grammar, body/evidence scale as one coupled hierarchy, evidence footprint, note area, orientation, table start/end and current footer. Preserve measured type levels, glyphs, palette and whitespace. A scientific object can retain its own typography independently of deck prose. Do not enlarge/reorganize the author's readable evidence to win preference, or add an abstract duplicate of one mechanism.
5. Decide how the audience recovers each public obligation using the [recovery contract](../recovery-contract.md). Add stable `objects` and `recovery` entries alongside the detailed geometry. A topic plus table headers may scope a format comparison; an equation and its types may already deliver operation relationships; existing evidence may carry conditions. Select only the prose actually needed for the current argument. Several facts may share one surface, and one qualifier may need joint surfaces. Metadata alone is not visible evidence. Preserve supported scope and uncertainty while avoiding repeated English inventories of table columns or mathematical terms.
6. Define copy slots: `id,role,factIds,boxPt,fontPt,paragraphGrammar,maxLines`. `paragraphGrammar` describes only permitted roles/nesting/emphasis, not new sentences. Short scientific labels and exact formal expressions may be frozen objects; leave copy-owned wording unfrozen. Define the semantic intent of selective emphasis and keep focus rows separate from comparison winners. Exact values and scientific relations remain immutable. Copy receives the approved recovery plan and role constraints; a genuine conflict returns to this owner.

Use `boxPt:{x,y,w,h}` in the handoff. Measured source `framePt:[x1,y1,x2,y2]` records are corners; convert width=x2-x1 and height=y2-y1 before authoring. Glyph bounds and PDF clipping frames are not recovered text-box padding. A negative font envelope is not proof that visible text is clipped; inspect rendered ink and repair true defects narrowly.

The plan carries roles and short scientific object labels, not newly written paragraphs. Budget from current facts and the author's density; add no redundant tutorial, caveat, section taxonomy or takeaway slot. Reserve an intact dominant plot before allocating notes. Keep one mechanism when one object carries all required relations. Compare regions and evidence/text scale with the selected reference before handoff. A short note band over dominant evidence and a narrative-led page with corner inset are distinct from a balanced sidebar spread. Diagram labels, a necessary local key and a prose witness may jointly deliver a fact; do not reserve every fact its own repeated text slot. If no family fits, record the gap instead of averaging the archive into a generic theme. New scientific data must drive the selected objects and emphasis; no old example experiment values, series or token counts are defaults.

Use the [compact inventory](../author-examples/family-inventory.json) to discover distinct procedure, paper-outline, table, plot and operator-graph roles without loading every specialist. A current method explanation does not itself require a new flowchart. Ordered prose, mathematical definitions and a supporting inset are distinct possible scientific objects.

All supplied author examples are training evidence. Former test cases promoted into this library and their later reconstructions cannot serve as fresh validation.
