# Reference layout routing

For the private Cerebras/NYU family, use [author profile](author-profile.md) plus the complete [training examples](author-examples/index.md). The PDF reader `scripts/inspect_pdf.py` can export actual selected-page renders and span-level size/font/color/bounds for a new PDF reference. It requires PyMuPDF. Its JSON is measurement evidence, not a recovered editable slide master. Inspect the PNG alongside it.

Choose a reference by the reader's scientific task: trace an indexed object, inspect exact configurations, diagnose a stage, or evaluate a pending explanation. Record evidence footprint and the specific phrases/cells emphasized. Inspect actual title absence, table-first order or sparse lower regions before introducing a new hierarchy. Rebuild native evidence from the new research record.

For style acceptance, the only blind-evaluation protocol is [blind evaluation](blind-evaluation.md). Keep scientific pixels intact. This supersedes older blanket advice to mask all headers or footers.
