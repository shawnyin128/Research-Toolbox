# Experiment Brief

Use when the user needs an executable design or a handoff to implementation. Combine fields naturally; do not expand a quick critique into a full protocol.

## Question and predictions

- Claim, intervention, observable metric, and scope.
- Observation versus hypothesis; evidence and assumptions.
- M1/M2/M0 accounts, shared assumptions, and possible coexistence.
- Prediction matrix with concrete intervention levels and a reason predictions differ.
- Unknown predictions, residual confounding, and what cannot be identified.

## Smallest sufficient test

- Substrate and why a smaller one loses the mechanism.
- Exact controls, baselines, fixed variables, and manipulated variables.
- Metric definition, units, aggregation, direction, and primary contrast.
- Data generation or split identities; training/calibration/selection/confirmation roles where relevant.
- Independent unit, replicates, uncertainty and sensitivity plan; deterministic checks instead where appropriate.
- Resource budget, runtime assumptions, and stop conditions. State unknown costs as unknown.
- Intervention, implementation, evaluator, and manipulation checks with observable pass conditions.

## Outcome-to-action table

| Pattern | Interpretation | Action |
|---|---|---|
| Failed validity/sensitivity check | Invalid or not informative | Repair before a mechanism claim |
| Valid M1-specific contrast | Conditional support in the tested regime | Apply practical expansion gate |
| Valid alternative-specific contrast | Strengthens the named alternative | Reframe the contradicted claim |
| Precise null excluding the required effect | Weakens the scoped thesis | Apply kill criterion |
| Wide uncertainty, mixtures, or shared predictions | Inconclusive/partial identification | Improve precision or separation |

Replace these generic patterns with operational ones. Define compatible kill/expansion thresholds, boundary cases, and branch precedence. Separate effect detection, mechanism identification, and practical value. State whether rules are predeclared, actually preregistered, or exploratory.

## Evidence and handoff

With supplied sources, include a ledger of statement, status (Source-supported / Inference / New hypothesis), and exact source location or missing evidence. Report novelty as unresolved unless checked.

End with one first experiment. If implementation is requested, hand over the intervention grid, protected controls, effective configuration, metric, data roles, budget, and decision rules together. Implementation or tuning must not silently change the scientific question.
